# Around The U.S.

Proyecto interactivo de galería de lugares desarrollado para el sprint 6 de
TripleTen. La página permite editar la información del perfil, generar tarjetas
desde datos en JavaScript y trabajar con modales.

## Funcionalidad

- Editar el nombre y la descripción del perfil.
- Renderizar tarjetas iniciales desde un array de objetos.
- Agregar nuevas tarjetas mediante un formulario.
- Marcar tarjetas con "Me gusta".
- Eliminar tarjetas del DOM.
- Abrir una vista ampliada de cada imagen en una ventana emergente.

## Tecnologías

- HTML5
- CSS3
- JavaScript
- Metodología BEM
- Diseño responsivo
